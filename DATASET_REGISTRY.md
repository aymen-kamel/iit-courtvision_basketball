# IIT CourtVision - Dataset Registry

Evidence labels: **[V]** verified on 11 November 2026 at the primary source (repo tree, raw file, Git LFS API, official page). **[S]** secondary source. **UNVERIFIED** = stated somewhere but not confirmed. Metrics are self-reported by each author on their own data and are not comparable with each other. Checks were metadata-only; no checkpoint or dataset has been downloaded. Compatibility classes for the RTX 3050 6 GB and the existing SmartPlay venv: **A** compatible in principle, **B** compatible with optimisations, **C** requires a separate environment, **D** impractical, **N** not verified. Context, licence matrix and benchmark plan are in [RESEARCH_REPORT.md](RESEARCH_REPORT.md).
